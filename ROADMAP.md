# Roadmap

Este documento describe la evolución planificada de CF Hilti Superba.

Las funcionalidades pueden modificarse de acuerdo con las necesidades del proyecto.

---

# Estado actual

Versión actual

**v1.0.0**

Características disponibles

- Aplicación PWA
- Funcionamiento offline
- Cálculo automático de materiales
- Reportes PDF
- Consulta de Juicios de Ingeniería
- Consulta de Fichas Técnicas
- Consulta de Sistemas UL
