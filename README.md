## 📄 Gestión documental

Los Juicios de Ingeniería, Sistemas UL y las Fichas Técnicas no forman parte del paquete principal de la aplicación.

Los Juicios de Ingeniería y Fichas Técnicas se almacenan en el repositorio y se descargan bajo demanda utilizando los enlaces Raw de GitHub, transformados mediante jsDelivr para permitir su visualización desde la aplicación.
Los Sistemas UL se cargan directamente de la base de datos de Hilti.

Esta estrategia reduce significativamente el tamaño inicial de descarga de la PWA.
